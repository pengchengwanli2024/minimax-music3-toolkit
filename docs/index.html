工作流

歌词.txt + caption.txt→ build_prompt.ps1→ prompt.json→ ComfyUI /prompt→ AR → DiT → VAE→ /view 下载 mp3→ 波形 + 频谱 PNG

三条命令跑起来

# 0) 环境自检（服务 / 版本 / 节点 / 模型 / 显存 / 队列）
pwsh -File .\scripts\doctor.ps1

# 1) 生成一首 30 秒测试曲
pwsh -File .\scripts\generate.ps1 -LyricsFile .\examples\02-gufeng-yanyudu\歌词.txt `
  -CaptionFile .\examples\02-gufeng-yanyudu\caption.txt `
  -Duration 30 -Seed 8823105 -Prefix 'Audio/quickstart' -OutDir .\out

# 2) 同一份词曲批量出多版（不同 seed / 不同时长）
pwsh -File .\scripts\generate_batch.ps1 -LyricsFile .\examples\03-poprock-ganlu\歌词.txt `
  -CaptionFile .\examples\03-poprock-ganlu\caption.txt `
  -Seeds 8823201,8823202 -Durations 190 -OutDir .\out
