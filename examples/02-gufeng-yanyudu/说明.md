# 示例 02 ·《烟雨渡》

古风叙事曲：侠客在江南渡口遇见撑伞的女子，一见倾心，因仇家要挟不得不离开，十年后两人在江南烟雨里重逢，只能把"珍重"留给彼此。

两个版本：

| 版本 | 文件 | 说明 |
|---|---|---|
| v1 | `歌词.txt` + `caption.txt` + `prompt.json` | 2 分 30 秒，古风电影感 68 BPM，温柔克制 |
| v2 | `歌词_v2.txt` + `caption_v2.txt` + `prompt_v2_A.json` | 2 分 50 秒，按"《烟花易冷》那类古风 + 现代 R&B 律动"重写：押韵统一、前奏 14 秒大鼓+古筝+笛起势、副歌升音区加和声 |

## v2 的押韵设计

| 段落 | 韵辙 | 韵脚 |
|---|---|---|
| Verse 1 | 江阳辙 | 香 / 光 / 旁 / 望 |
| Pre-Chorus | 言前辙 | 衫 / 绊 / 宽 / 天 |
| Chorus | 人辰-中东混押 | 城 / 等 / 整 / 声 / 身 / 分 / 尘 / 程 |
| Verse 2 | 江阳辙 | 扬 / 凉 / 望 / 霜 |
| Bridge | 由求辙 | 走 / 首 / 留 / 手 |

副歌钩子（重复三遍）：

> 烟雨纷纷 落满了江南城 / 我听闻 你还在渡口等 / 一盏灯 一个人 十年整 / 等成我 心口最疼的回声

## 复现

```powershell
pwsh -File .\scripts\generate.ps1 `
  -LyricsFile .\examples\02-gufeng-yanyudu\歌词_v2.txt `
  -CaptionFile .\examples\02-gufeng-yanyudu\caption_v2.txt `
  -Duration 190 -Seed 8823111 -Prefix 'Audio/yanyudu_v2' -OutDir .\out
```

> 实测：150 秒版 259 秒出结果；190 秒版约 296~336 秒。同一份词曲换 seed（本仓库给过 8823111 / 8823112 两版）差异主要在演唱情绪和副歌走向。
